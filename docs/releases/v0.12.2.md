# TermiX 0.12.2 · Editor search and local files

- Find and replace in the current file with previous and next match, count, case, whole words and wrap-around. Jump directly to a line.
- Use a single toolbar without a horizontal scrollbar and theme-matched selectors. End a comparison with the dedicated action.
- Open a local UTF-8 file through the Windows picker as a read-only tab. Compare it with a remote file in the same editor workspace.
- Close the editor with X or Escape and reopen its retained tabs. Clicking outside keeps the editor open.

Available as EXE, MSI and portable ZIP. Keep the portable data folder when updating.
