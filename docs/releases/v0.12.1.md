# TermiX 0.12.1 · Terminal macros and editor workflow

- Start a labeled macro recorder and type directly into the selected terminal. Review and edit captured text and Enter steps before saving. Special keys stop capture.
- Keep open editor tabs and unsaved buffers when dismissing the editor. Distinguish same-named files by path, choose any two tabs to compare, and swap the comparison sides.
- Use a single row of icon-labeled editor tools and adjust the visual tab width. Open up to eight UTF-8 documents per SSH connection, up to 2 MiB each.
- Resize and filter the local SFTP list. Type a path inside the selected folder tree or select a new root through the Windows folder picker.
- Find language in the first settings category, Appearance. Sidebar tabs align with the terminal tabs.

Available as EXE, MSI and portable ZIP. Keep the portable data folder when updating.
