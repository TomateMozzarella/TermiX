# TermiX v0.9.0 — Readable terminals and remote monitoring

Windows development prerelease. Save work before upgrading. EXE, MSI and portable ZIP remain available.

- Fixes terminal cursor/font rendering and overlapping Monaco lines caused by runtime CSS under the installed Content-Security-Policy. Keeps script restrictions; tests include Tauri-style CSS hashes.
- Fixes native window closing: one coordinated unsaved-work prompt, with the required main-window-only destroy permission.
- Linux SSH monitoring shows CPU/RAM/root disk, network rates, uptime, visible sshd sessions and logged-in users. Uses a separate read-only channel on the existing verified connection; pause via Monitoring. Initial CPU/network deltas need a second sample. Linux tools, namespaces and permissions determine availability; other operating systems are not yet supported.
- Compact saved command names; hover shows text. Right-click to run/edit/delete or double-click to run after target confirmation.
- Mouse side/back button navigates previously visited SFTP directories. Terminal display highlights plain URLs, IP addresses, prompts and status words without rewriting remote output or existing ANSI colours.
- Settings keep the same viewport-bounded dimensions between categories and scroll internally. Controls, menus and panels share calmer rounded styling.
- Show up to six existing terminal tabs in a grid through the tab context menu. Rotate or remove the grid without restarting transports. Multi-Execute/broadcast remains planned.
- External editors now receive the safe original filename in an isolated temporary folder. Remote SFTP files still need a local copy; saved changes require explicit transfer and retain server conflict checks.

Portable updates keep data beside the EXE; Windows passwords remain on the PC. Interactive uninstall choices, broader native/editor/server compatibility, real startup timing and independent review remain manual. SSH tunnels move to v0.10.
