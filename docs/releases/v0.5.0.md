# TermiX v0.5.0 — SFTP and workspace interaction

Development prerelease for Windows 11.

- Open Files on a connected SSH tab to browse the server through the same verified connection. Navigate paths, upload/download individual files, follow progress and cancel transfers. Local files/destinations are selected in native Windows dialogs.
- Destinations are preserved while transferring to exclusive partial files. Remote replacement requires explicit opt-in; errors/conflicts remain visible. Symbolic links and recursive directory transfers are not supported.
- Drag saved sessions onto folders or Unassigned. Resize the sidebar and SFTP panel, collapse sidebar sections, reorder tabs by dragging and close tabs with the middle mouse button. Running terminals retain their processes.
- English/German interface; existing settings and library are preserved.

SSH CPU/RAM/disk/user monitoring is recorded for a v0.5.x follow-up. Actual editing remains v0.6 and macros/split terminals v0.7. Explorer drag/drop, dual-pane local browsing, recursive/resumable transfers and non-Windows native dialogs remain planned. Interrupted connections can leave named partial files; no automatic resume occurs. Installed interactive and independent security checks remain separate from CI.

Install the EXE or MSI after closing TermiX. SHA256SUMS and release-manifest.json identify the exact tested source and installer hashes.
