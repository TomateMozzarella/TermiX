# TermiX v0.6.0 — Remote editing and Windows workspace fixes

Windows development prerelease. Close active work before upgrading.

- Monaco editor: UTF-8 text up to 2 MiB, eight file tabs, syntax highlighting, find/replace, explicit Save to server / Ctrl+S. Server content changes block overwriting. Unsupported atomic replacement fails safely.
- Configured Notepad++/VS Code/custom executable can edit an explicit temporary working copy. Reload external changes, review them, then save to the server. No automatic upload. Unsaved copies may remain in user temp after an app crash.
- Fix Windows session/folder and tab HTML drag/drop by disabling Tauri native file interception. Browser tests alone did not expose this Windows integration issue in v0.5.
- Choose SFTP left or right and an initial directory in settings. A dot uses the SSH user's server-provided starting directory (often /root for root). Terminal cd is independent.
- Align upload controls; add session-list and SFTP context menus, including folder creation. Independent terminal light/dark palette and full ANSI colours improve readability; colours sent by the remote shell remain under its control.
- Installer checks the exact installed application path and offers to close it. Upgrade tests preserve session metadata, settings and known host keys. Active terminal processes close; unsaved editor buffers are not persisted.

Native GUI gestures, interactive installer cancellation and wider editor/server interoperability remain manual validation items. Linux-first SSH monitoring, automatic folder following, additional encodings and automatic sync remain pending. Release assets include EXE, MSI, SHA256SUMS and the exact-source manifest.
