# TermiX 0.11.0 · Workspace redesign

The actions you use across SSH sessions are now within reach from the main toolbar.

> Development prerelease · Windows x64 · Unsigned

## Download

- [Windows setup EXE](https://github.com/TomateMozzarella/TermiX/releases/download/v0.11.0/TermiX_0.11.0_x64-setup.exe)
- [Portable ZIP](https://github.com/TomateMozzarella/TermiX/releases/download/v0.11.0/TermiX_0.11.0_x64-portable.zip)
- MSI, SHA256SUMS and the build manifest are also available in Assets.

## New

- Open a connection, change the split layout, manage SSH tunnels or open Help from the toolbar.
- Show up to six terminals. Multi-Execute previews the targets and sends one command to the ready terminals visible in the split after confirmation. At least two are required.
- Press R in a disconnected SSH terminal to reconnect through the normal verification flow.

## Improved

- Start with an empty workspace. Open a terminal or restore a previous workspace when needed.
- Saved session folders start collapsed. Search matches names, hosts, usernames and folders even when folders are collapsed.
- Tab, terminal and SFTP menus group actions with icons. Tab colours remain available as swatches.

## Updating

Save open work before updating. Run the setup EXE for an installed copy. When replacing a portable copy, retain its data directory.

## Scope

Multi-Execute reports command delivery to the terminal, and command results appear in the respective shells. Additional connection protocols remain on the roadmap.

**Deutsch:** Neue Werkzeugleiste, bis zu sechs sichtbare Terminals, Multi-Execute mit Zielvorschau, SSH-Wiederverbindung per R und Suche in zugeklappten Ordnern.
