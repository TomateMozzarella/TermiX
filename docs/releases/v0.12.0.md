# TermiX 0.12.0 · Editor workspace and Remote Desktop

## Connections

- Save RDP connections in the session library and open them in Windows Remote Desktop. Windows handles authentication and certificate prompts.

## TermiX Editor

- Hide the editor while browsing SFTP. Open another file and compare it with a retained tab.
- Use clearer tabs, search icons and highlights, go-to-line, word wrap and tab width controls.
- Open a terminal output snapshot in your preferred editor. External editors receive a temporary local text copy.

## Workspace

- Main and editor toolbars use uniform button sizes.
- External files appear in the status bar. TermiX uses its own confirmation dialogs for closing the app and discarding editor changes.
- Uploading edits from an external editor requires confirmation. Server conflicts block overwriting.

## Current development follow-up

- Detachable terminals retain their live process and scrollback. Confirmations use TermiX dialogs, including in detached windows.
- SFTP downloads can reuse a verified local partial after reconnect or restart. Uploads can pause and resume within one connection. After a disconnect, an interrupted upload starts again in a new staging file. Folder retries skip verified identical files.
- OpenSSH, PuTTY and MobaXterm imports preview compatible SSH entries. PuTTY and MobaXterm entries without a saved username are skipped.
- Read-only monitoring covers Linux, FreeBSD, macOS and Windows, with platform-specific counters.

Native Windows application validation and live SSH checks are pending for these follow-up changes.
