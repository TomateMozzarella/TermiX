# TermiX 0.12.0 · Editor, workspace and remote connections

## Connections

- Save RDP connections in the session library and open them in Windows Remote Desktop. Windows handles authentication and certificate prompts.

## TermiX Editor

- Hide the editor while browsing SFTP. Open another file and compare it with a retained tab.
- Use clearer tabs, search icons and highlights, go-to-line, word wrap and tab width controls. Format JSON, CSS and HTML on demand, then review before saving.
- Open a terminal output snapshot in your preferred editor. External editors receive a temporary local text copy.

## Workspace

- Main and editor toolbars use uniform button sizes.
- External files appear in the status bar. TermiX uses its own confirmation dialogs for closing the app and discarding editor changes.
- Uploading edits from an external editor requires confirmation. Server conflicts block overwriting.

## Transfers, session imports and monitoring

- Detachable terminals retain their live process and scrollback. Split dividers are adjustable, and the workspace remembers its split and collapse state. Confirmations use TermiX dialogs, including in detached windows.
- Browse local files beside SFTP and confirm uploads dropped from Windows Explorer. SFTP downloads can reuse a verified local partial after reconnect or restart. Uploads can pause and resume within one connection. After a disconnect, an interrupted upload starts again in a new staging file. Folder retries skip verified identical files.
- Create desktop shortcuts and SSH defaults, ping a saved host or open multiple saved sessions together. OpenSSH, PuTTY and MobaXterm imports preview compatible SSH entries. PuTTY and MobaXterm entries without a saved username are skipped.
- Read-only monitoring covers Linux, FreeBSD, macOS and Windows, with platform-specific counters.

## Commands and shortcuts

- Record explicitly submitted commands as a macro and assign shortcuts in settings.

## Windows downloads

Choose the EXE installer, MSI package or portable ZIP. Preserve the portable data folder when updating. Use the included checksums to verify the download.

Live interoperability with every supported remote OS and editor remains outside the automated test coverage.
