# TermiX v0.7.0 — Editor and terminal productivity

Windows development prerelease. Save work before upgrading; active processes close.

- Choose direct external opening in Settings → Preferred editor, or keep the integrated editor. External copies are never uploaded automatically: reload, review, then explicitly save. Closing the working-copy dialog removes its copy; close the external application first. Conflict protection remains active.
- Sessions and SFTP share one sidebar by default. Settings → Files also offers a separate left/right panel. Expand session folders and remote directory children; opening a directory still navigates into it. Remote tree expansion is bounded and never follows symbolic links recursively.
- Settings are grouped into Language, Default terminal, Appearance, Preferred editor and Files. Appearance previews keep shells running.
- Editor toolbar exposes Find, Replace (next/all), a read-only comparison of two open files, and maximize/restore. Existing Ctrl+F, Ctrl+H and Ctrl+S remain available. UTF-8/2 MiB/eight-document limits still apply.
- Tab context menu: rename, duplicate, pin, colours, close left/right/others/all, focus view and two-pane split/rotation. Pinned tabs survive bulk closure. Existing connections stay running when split or reordered.
- Terminal context menu: copy/all, paste, select all, search, font size and clear scrollback. Multiline context-menu paste asks for the target confirmation. Standard keyboard terminal paste retains xterm's normal behavior.
- Ctrl+Shift+P opens a searchable command palette. Named command snippets live in memory for this app session and require an explicit target and confirmation on each execution. No recording, auto-run or persistent snippet storage.
- Restore workspace explicitly reopens saved tab references/order, pins/colours and panel widths. SSH tabs require manual Reconnect and the normal verification/authentication flow. No terminal output, history, passwords, keys or macro commands are saved in workspace.json.

Still planned: SSH monitoring, persistent non-secret snippets, configurable shortcut mappings, detached/multi-monitor windows, draggable split ratios, printing/output recording, Explorer transfers, additional encodings and automatic folder following. Native desktop gestures, interactive installer choices and wider editor/server interoperability remain manual validation items. The release includes EXE, MSI, checksums and source/run provenance.
