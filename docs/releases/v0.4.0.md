TermiX 0.4.0 is a Windows x64 development prerelease.

- Edit, duplicate and delete saved sessions while existing terminals keep running.
- Create/rename folders, assign sessions and delete folders without deleting their sessions.
- Favorites, recently used sessions and search across session/folder details.
- Larger, higher-contrast interface text and independent 100–150% UI scaling; terminal font size stays separate.
- Paste hostnames, IPs or http(s)/ssh addresses. Normalization shows the SSH destination and preserves an explicit port; HTTP(S) does not imply SSH port 80/443. Ambiguous addresses receive actionable errors.
- Native EXE selection and optional installed-editor discovery for Notepad++/VS Code, with visible manual override. Configuration never launches an editor.
- Versioned session library, legacy backup, atomic saves, rollback on failure and protection against stale/concurrent library writes.
- Explicit metadata-only JSON import/export with import preview. Existing session IDs are not overwritten; passwords/private keys/host-key trust are not exported.

Choose the **x64-setup.exe** installer for the guided Windows installation. Close TermiX before upgrading. Existing preferences and saved sessions are retained; the old session-array file is backed up before its first migration write.

English is the default; German is also available. UI size and editor paths can be changed in Settings.

SFTP/file browsing, actual external/integrated file editing and macros remain later roadmap milestones. SSH retains host-key verification and opt-in Windows Credential Manager storage. Independent security review and broader installed-app/interoperability checks are still outstanding.

SHA256SUMS and release-manifest.json identify the installers and exact tested source commit. These checksums establish build provenance; they are not an independent security audit or an Authenticode signature.
