# TermiX 0.11.1 · Workspace polish

The workspace now brings the tabs, menus and dialogs closer to the approved design.

> Windows x64 development prerelease. Builds are unsigned.

## Downloads

- [Windows setup EXE](https://github.com/TomateMozzarella/TermiX/releases/download/v0.11.1/TermiX_0.11.1_x64-setup.exe)
- [Portable ZIP](https://github.com/TomateMozzarella/TermiX/releases/download/v0.11.1/TermiX_0.11.1_x64-portable.zip)
- The MSI and checksums are available in Assets.

## Changes

- TermiX starts maximized with the Connections section collapsed.
- Scroll through open tabs with the mouse wheel or the arrow buttons. The new tab button stays in view.
- See the arrangement and current selection before switching to a layout with up to six terminals. Split panes show the session title and connection type.
- Identify the active tab and tab colours more easily in the rounded tab strip.
- Open Help at the right end of the toolbar, next to Settings. New Connection is the primary action.
- Scan terminal and tab context menus with a single line between groups.
- Configure listening addresses and destinations in separate sections of the SSH tunnel dialog. Active tunnels have their own list.
- Review each Multi-Execute recipient by session name and endpoint.

Save open work before updating. For a portable update, keep your existing data folder.
