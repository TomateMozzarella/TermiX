# TermiX v0.8.0 — Portable and everyday workflows

Windows development prerelease. Save work before upgrading.

- Download the EXE installer or portable ZIP from this release. Extract the complete portable ZIP to a writable folder, keep portable.flag and start TermiX.exe. Data and the WebView profile live in its data folder. Keep data when replacing application files. WebView2 Runtime is required, normally already present on Windows 11.
- Portable sessions/settings/commands are separate from the installed app. Windows Credential Manager passwords remain on this PC/user and are isolated by portable-folder location; they do not travel on a USB drive.
- The EXE uninstaller asks whether to remove saved installed-TermiX credentials, default No. Silent uninstall/upgrade and MSI uninstall keep them. Portable credentials, other programs and private-key files are preserved.
- A Commands tab beside Sessions/SFTP stores named terminal commands across restarts. Add/edit/delete/search and run in a clearly identified target after confirmation. Never store passwords, tokens or private keys here; nothing runs automatically.
- SFTP uses a compact icon row with tooltips: download, upload, refresh, create file/folder and delete selection. File creation is exclusive; folder deletion works only when empty. Replacement remains opt-in under Options. Long permanent help text and the duplicate top-right Files button are removed.
- A themed first-paint surface replaces the blank white opening. The native window waits for the styled UI before showing, with a bounded fallback.
- External editors open without a blocking intermediate dialog. Returning without changes leaves the terminal usable. Stable saved changes trigger a transfer offer when TermiX regains focus; Later postpones them, and explicit transfer retains server-conflict protection. External files are managed in a small nonmodal status area. No automatic upload. Finish editing after closing the external program; temporary copies can remain after crashes or disconnected sessions.

SSH tunnels move to the following milestone. SSH monitoring, advanced macro recording, recursive transfers and independent security review remain pending. Native interactive uninstall choices, additional external editors/servers and real startup timing remain manual validation items.
