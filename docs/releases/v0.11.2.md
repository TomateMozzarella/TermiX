## Changes

- Keep the four preset tab colours or pick your own colour from the tab menu.
- Import and export commands from the Commands sidebar. Review a JSON import before merging it with the local library.
- Right-click a session to open, edit, duplicate or export it. SSH sessions also offer an alternate login and direct access to SFTP.
- Right-click a folder to create or import sessions into it, expand it, rename it, export it or delete it.
- Open terminal scrollback as a read-only snapshot in the integrated editor.

Save open work before updating. Keep the existing data folder when updating a portable installation.
